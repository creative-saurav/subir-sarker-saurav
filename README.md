# Portfolio Landing Page (React + Framer Motion)

Quick scaffold for a portfolio landing page using Vite, React and Framer Motion.

Run locally:

```bash
npm install
npm run dev
```

Files to edit:
- App: [src/App.jsx](src/App.jsx#L1)
- Sections: [src/sections](src/sections)

Customize texts, images and add real project links.
